ZZ Trading Co.

Project Mission Statement:

ZZ Trading Co manages and operates 3 brick and mortar locations that specializes in selling trading card box sets. Since growing the business, keeping track of all sales and inventory manually has been much harder to manage. The Trading Card Box Set Sales Management System aims to have a database to manage StoreInventory, Invoices(sales), and Customers for each of the Stores. The front end will allow the enterprise to have an intuitive user experience to manage their business. This full stack solution will help close the gap on any processes that may have been manually tracked, reviewed, and managed in a non-centralized location. Each year each location can sell around 500 trading card box sets across different genres of box sets. Totaling ~1,500 box sets per year.
